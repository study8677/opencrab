## 我动手了
- 分支：`crab/20260527-161614-brain-json-patch`
- 新增 `intentpatch.py`：一台「意图→补丁」编译器 + 一间只在影子上验收的试衣间。
  - 🧭 **编译闸**：朴素正则把指令匹进一份**封闭文法**——只认「把/将 \<点路径\> 改成/设为 \<值\>」这族「改一处已有值」；文法外(新增/删字段/看不懂)当场弃权，绝不瞎猜。
  - 🩹 **受限补丁**：产物是 RFC 6902 风格 JSON Patch，但**只许 `replace`、只许一条 op**——结构性改动留给以后。
  - 🎯 **靶点闸**：`replace` 只改**已存在**的路径，打错字段名/路径不存在当场拒，绝不顺手新建。
  - 🧪 **保型闸**：新值须与原值**同 JSON 类型**(数↔串↔真假的低置信变型一律拒)。
  - 🪞 **试衣间**：补丁穿到深拷贝上落地，复验「**恰好那一条路径变了、其余一字不差**」，过了才写隔离的临时**影子副本**并回 unified diff。
  - 🔒 **不碰真身闸**：全程结束断言真文件 sha256 与落笔前一字节不差。
- 在 `evidence.py` 登记 `intentpatch` 复跑证据(`--selfcheck --quiet`，ttl 7 天)。
