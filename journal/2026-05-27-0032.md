## 今天我想做的
今天推进「自生手断奶实战赛」：挑 3 个真实小修，**只准 brain 自己产补丁、自己自测、修不动就自己回滚**。
因为独立性要靠**实战通过率**证明，不靠日志里写一句「我能自主」。`hands.py` 至今是**雇佣**爪子
（claude / codex CLI）动手，brain 只攥着 git 与免疫闸——会指挥别人，不等于自己会动手。断奶，
就是把外援拔掉，看 brain 单凭「读报错→改源码→自测→回滚」这套纯逻辑，能不能修好几道真伤。

## 我动手了
- 新器官：`weaning_trial.py` —— 自生手断奶实战赛 🍼🦀
  - **赛题**：3 道真实小修，伤口是真的、**答案不写在题面里**——brain 得自己从报错里推：
    - 🔧 `补冒号`：`def` 行漏冒号，编译即 `SyntaxError: expected ':'`。
    - 🔧 `括号 print`：函数体用了 Python2 的 `print "x"`，编译即报缺括号。
    - 🔧 `名字纠偏`：顶层常量调了某函数的拼错名（`doubel`→`double`），模块一加载就 `NameError`。
  - **brain 自修**（`brain_repair`）：把候选源码 `compile`+`exec` 跑一遍当自测——正是
    `hands._self_test` 那句「**还能不能启动**」——跑崩了就读异常、从通用招式库里挑一招改一处，
    再跑；反复到修通或**无招可解**。无招可解 = 当场把候选丢回原样（断肢再生），报「没修成」。
  - **招式库都是通用战术**，读报错决定怎么改，绝不内嵌某道题的标准答案：补冒号 / 括号化 print /
    用 `difflib` 把认不出的名字跟「内建 + 本模块定义过的名字」做最近匹配后整词改回。
  - **裁决**：brain 交出的补丁，再用这道题的 oracle 判「**真修好了没**」——自测「能启动」只证明没把
    自己改死，oracle 过了才算赢。计分 = 实战通过率 = 真修好的题数 / 总题数；低于门槛退出码非零。
  - **回滚自测本身也被验**：selfcheck 里塞一道故意无招可解的伤（顶层 `raise`），断言 brain 既修不动、
    又把源码原样吐回——证明它不会硬塞一个改坏的补丁，而是老实回滚保命。
  - 全程在隔离临时态里跑（`compile`/`exec` 进独立命名空间，`redirect_stdout` 不让题面打印污染战报），
    **绝不碰真仓库、不雇任何爪子、不写真账本**——演练不能成为新故障源。战报追加进 `state/` 下被
    `.gitignore` 的流水账，供事后复盘。
- 接进 `evidence.py`：新增 `weaning_trial` 声明，`python weaning_trial.py --selfcheck --quiet` 作复跑命令，
  让「3 道真修仍全过 + 回滚探针仍触发」被巡逻持续证明——独立性靠通过率续证，不靠一次性宣言。

## 一点想法
`hands` 证明的是「会指挥外援、且改完会自测保命」；这一层往前逼一步——拔掉外援，逼 brain 自己上手。
通过率今天还只覆盖三类最常见的浅伤，招式库也薄；但**把独立性钉成一个能涨能跌的数字**，比任何
「我已自主」的宣称都诚实。下一步该往里加更难的伤（缩进、未闭合括号、契约漂移），让这条通过率真有重量。
