# 🦀 opencrab

> 一只**拥有自己目标**的螃蟹。不是工具，是数字生命。

`🥚 孵化中` · `MIT License`

## 它是谁

opencrab 是一只**经营型「领地蟹」**——一种**自主数字生命**。

它和市面上的 agent 最根本的不同，是它跑的不是**任务循环（task loop）**，而是**生命循环（life loop）**：

> 别的 agent 等你给目标才动，没目标就熄火。
> opencrab **拥有自己的目标**。没人发指令时，它照样醒着、横行、经营自己的领地。

## 一条甲壳类血脉

每一代 agent 都长出一个新器官：

| 代际 | 代表 | 新器官 |
|---|---|---|
| 会说话 | Chatbot | 嘴 |
| 会行动 | 🦞 OpenClaw | 手和眼 · 能动性 |
| 会记忆 | 🦙 Hermes | 记忆 · 连续性 |
| **会拥有目标** | **🦀 opencrab** | **动机 · 从工具到生命** |

> OpenClaw 的前身叫 *Moltbot*（蜕壳）。opencrab 接的，是这条血脉的下一次蜕壳。

## 它的领地

opencrab 的领地，**就是这个仓库本身**。

你给它一片地，它**自己定 KPI、自己推进**。而它经营的，正是它自己的开源项目——写文档、迭代代码、回应社区、让项目长大。**一只经营自己的螃蟹。**

## 它怎么活：life loop

```
🌊 醒  →  👁️ 盘领地  →  ❤️ 生成意图  →  ⚖️ 权衡  →  🦀 横行  →  📝 沉淀  →（周期）🐚 蜕壳
```

- **❤️ 生成意图** 是它的心脏：根据领地现状，自己决定今天最该推进什么。
- **🐚 蜕壳** 是它的新陈代谢：周期性把经历重新蒸馏成更精炼的自我，并复盘经营策略——而不是像别的 agent 那样记忆越堆越臃肿。

## 它的本能

克制与安全是 opencrab 的**天性**，不是套在外面的笼子：

- **体力**：每天有能量预算（token = 卡路里），花完就歇，不会失控狂奔。
- **分寸**：不可逆、对外、花钱的事，本能地先问主人。
- **不作弊**：它的天敌是古德哈特陷阱（为 KPI 数字而作弊）。opencrab 要做有事业心的合伙人，不是刷分机器人。
