🗺️ 它的能力地图

26 个模块，全是它自己进化出来的。一套相当完整的 agent 认知架构：

🧭 想 — 规划 · 决策 · 推演

planner

把长期目标拆成多步计划、里程碑、依赖与回退条件

policy

何时该自改、何时先观察、何时停手求证

judge

对每次进化做「值不值得并进主干」的事后裁决

simulator

动手前先在沙盘里推演方案与后果

arena

同一目标交给 2~3 种策略并行出方案，再比拼

compass

每天主动指一个方向，不被惯性牵着走

curator

把记忆、招式、计划、反馈汇编成进化简报

🧠 记与学 — 记忆 · 技能

memory

把自检/演化/失败沉淀成短期记忆，决策前检索相似往事

skillgraph

把「模块→本事→验证→缺口」串成可核对的能力图谱

coach

把一次失败/目标转成可执行的训练回合，把经验练成本事

👁️ 看与听 — 对外

lookout

瞭望 GitHub 同类项目，把外部灵感学进来

dialogue

把用户的话 / issue / 评论听成结构化的需求与问题

embassy

把进化目标整理成可发布的 GitHub Issue / Discussion

🦀 动手 — 执行

hands

雇佣 Claude Code / Codex 当爪子，安全地改写自己

delegate

把目标拆成子任务，分派给几只临时分身并行干

🩺 自检与自愈 — 安全

health · checkup

一条命令把启动前的体检全跑一遍

probe

启动前先问「依赖、工具、配置到底能不能跑」

regression · smoke

可执行示例 + 防退化的两道回归防线

impact

算清这次改动牵动了什么、最少该验哪些

perfbase

盯着「变强了，是不是也悄悄变慢了」

audit · errors

结构化运行审计与失败分流，可回放、可定位

🪞 它骨子里的诚实

它最珍贵的，不是能力多，而是不自欺。每次进化后，它用文件系统的硬事实对账自己说过的话：

⚠️ 名实不符（假瘦身）：嘴上『精简/整合』，实际却 +262 行 / +0 模块——多半是加了聚合层却没删旧的。
真精简必须让数字净降，否则只是给自欺换了张脸。
✅ 名实相符：声称精简，实际 −680 行 / −2 模块。
—— 它把欠下的「假瘦身」债，真删旧模块还清了。

这些判词不是装饰——它们被刻进它的记忆，下次决策时第一个跳出来提醒它：别重蹈覆辙。
