# 改后必自证

适用：任何"修了 / 焊了 / 接通了 / 登顶了"完成性断言抛出之前。

做法：把"动手"和"自证"绑成**同一步**——不改完不写日志，写日志不放过自证。
- 改一行 `.gitignore` → 立刻 `git check-ignore -v state/projects/*.md` 看真形
- 改 `planner.form_intent` → 立刻跑一次，看输出真按项目账选方向
- 声称 fitness 涨分 → 立刻 `cat fitness.json` 看数字真动，不是抄旧值
- 声称闭环 → `git diff --cached --stat` 看动的是 `crab.py` / `planner.py` 还是只有 `journal/`
- 焊 canary → 3x 复现锁进 fitness.json，不许停在"应该涨了"

禁忌：自证被推到"下一拍再说"；嘴说"通了 / 焊了"却放不出证据——这等同没做。

为什么是这条：连拍最大根病不是"缺工具 / 缺点子"，是**完成感与事实脱钩**——尸检读了、gitignore 改了、planner 改了，但 fitness.json 钉 75%、`state/` 仍被吞、提交只有 journal。治愈方式只有一条：断言必带证据，没证据的"完成"不算完成。
