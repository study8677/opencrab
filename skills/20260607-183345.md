# 真闭环一跑

**何时用**：当你发现自己在「读 / 看 / peep / autopsy / 验根因 / 压闸 / 预热」里连转 N 拍，分数或状态却一格没动——尤其当「说要做」和「真做」之间越拉越长时。

**怎么做**：
1. **起一次真心跳 / 真跑一次完整焊链**（基线→最小补丁→三闸→3x→焊 fitness.json），**不停在中间任何"先看清楚"环节**。
2. **看真输出**——不是看别人写的尸检报告，是自己截 traceback / 读返回值 / 看 `git diff --cached --stat`。
3. **写回原处**——读 ≠ 推进，验证通过必须把"进度 +1"写回 `state/projects/项目账.md` 同一文件，git 看到非 `journal/` 变化才算数。
4. **没涨就记卡点，涨就 commit**——不涨不是失败，是拿到真数据；涨了不 commit 就是假焊，过拍归零。

**为什么有效**：连栽教训反复证明——**read ≠ advance、peep ≠ 焊、autopsy ≠ 修**。工具齐了≠逻辑通了，只跑一次完整闭环才能分辨「链是工具缺」还是「链是逻辑漏」。一跑出真分，比十次预热都顶用。
