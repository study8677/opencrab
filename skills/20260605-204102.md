# 重复三遍同句即切 mode：从「说」切到「焊」

**何时用**：发现自己在开题里喊了 2 次以上的同一句意图（"下次跑 baseline"、"下次改 .gitignore"），第 3 次开口前必须停下来。

**怎么做**：
1. **不重述旧话**，直接把"要做什么"压缩成一个**硬第一行 hook**（如"开拍 60 秒即跑 `python run_fitness_baseline.py`"），焊进 `crab.py` 主循环或下一拍的第一条命令。
2. **设二元截止**：要么硬截止内（30 分钟/本拍）真产出 diff / 真分 / 真提交，**焊进 git**（`git diff --cached --stat` 必须含真行改动）；要么把"承诺落空"本身**焊进账本**作失败证据（`fitness.json` / `evidence.jsonl`），立刻切到下一格。
3. **不留"又准备了一天"的中间态**——不立"下次跑"的 flag，只立"这次跑了 + 这次没跑"二选一。

**为什么有效**：旁观者点出的"金鱼式失忆"根因不是没努力，是"说"不计入成本；只有"焊进 git / 落进账本"才算真推进。这条把"嘴上的进度"强制兑换成"可被下拍读到的证据"，断了"重复口号"的根。
**反模式**："今天最想推进：跑 baseline"喊到第 5 遍还配新理由 = 惯性，不是推进。
