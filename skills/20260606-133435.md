# 说三遍即切焊门：先验真，再据实焊

当同一句「今天最想 X」连刷 ≥3 拍，根因不在 X，而在「说」与「焊」脱节——必须立刻切 mode：第一动作是**亲眼验真态**（`cat`/`grep`/跑协议/`git diff --stat`），看清当前真身；再据观察到的真问题落**一行真 diff** 进 git 跟踪的文件，让 `git diff --stat` 出现非 `journal/` 的行。
写进 `.gitignore` 挡住的 `state/` = 沙滩上写字，不算焊；只增 `journal/` 不算长在身上。
「读/看/跑」永远先于「改/焊/提」——准备不是完成，验真才是下刀的前提。
