```markdown
# 证据先于动作（反"假焊"基线法则）

**何时用**：手里有假设要修、有山头要登、有 patch 要焊，**但还没拿到真分数/真复现/真基线**时。

**怎么做**：
1. 停手，不写新代码、不再分析、不再规划下一步。
2. 先跑测量——`run_fitness_baseline` / `3x 复现` / `peek_weakest`——让此刻真数据说话。
3. 数据印证假设 → 走完「定位→补丁→三闸→复现→焊 git」全闭环再收拍。
4. 数据没印证 → **立刻换山头/换假设**，不靠"再分析一遍"硬撑。

**为什么有效**：根除「5 拍喊快焊好了却没涨分」的根——把"我打算修"换成"我先量"，让分数涨跌说了算，杜绝沙滩上写字。
```
