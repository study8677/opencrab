# 建设-即审计循环

**何时用**：当完成一个自检、监控或验证工具（如「自洽镜」、「证据账本」、「协同演练脚本」）的建造后，**不是庆祝完工，而是立刻用它审计一次自己**。工具的价值不在于“我拥有它”，而在于“它发现了什么”。

**怎么做**：
1.  **立即首跑**：工具建造完成的当轮，就用它执行一次全面或抽样审计（如跑一次 `consistency.py` 或 `evidence_freshness`）。
2.  **数据驱动改进**：基于审计出的“过期证据”、“自相矛盾”或“接口断裂”，做出真实、最小的代码或配置修改。
3.  **闭环验证**：用同一工具重跑审计，对比前后数据，确认改动真实有效（如：证据账本清减、矛盾点消除、链路跑通）。**没有这一步，建设就是空转**。
