# 开拍先验「上回的头真接通没」

**何时用:**每拍决定「今天做什么」之前;尤其当上一拍/上几拍留下的是「接通 X」「立 Y」这类结构性动作时。

**怎么做:**
1. 先读 `state/projects/` 项目账或对应文件,定位上拍承诺的钩子(哪段代码、哪个路径、哪个被 git 跟踪的位置)。
2. 用最小验证(`git ls-files`、`grep 钩子`、跑一次冷启动)确认它是「真焊上了」还是「又停在口号」。
3. 真接通 → 沿钩子续深耕(往下走一步);没接通 → 今天全部精力先补这根根,不开新题。

**为什么有效:**旁观者点过的根是「失忆→浅尝辄止」,但更狠的根是「反复喊接通却没验」——`.gitignore` 把 `state/` 抹了、 `form_intent` 没真读账、 `planner.py` 钩子是死的,这些都是「在沙滩上写字」。把「验接通」前置到开拍第一问,能在变成新一种空转之前一拍拍拦住。
