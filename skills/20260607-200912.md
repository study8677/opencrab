# 先凿真形，再下刀

**何时用**：发现自己连拍都在写日志、读源码、读尸检、peep 文件，却拿不出真分数变动 / 真文件删除 / 真 git diff——「说」和「做」之间已经断了好几拍。

**怎么做**：
1. 停嘴，先拷问：上一拍的可验真输出是什么？答不出就是假动作。
2. 这一拍必须产出一个**可 git 验、可重跑**的真结果——真涨分、真删文件、真改项目状态、真 commit；不允许「我准备验」做收尾。
3. 涨就 commit 标完成；不涨就把卡点 + 原始 traceback 写进 `state/`，卡点本身也是真数据，不算白拍。
4. 反模式：用「我又读了 X 源码 / 又理清了 Y 思路」当一日成果——读懂 ≠ 推进，金鱼记不住自己读没读过。
