# 先验真再开山

**何时用**：每拍喊"今天真焊 X"前——尤其同一山头喊了几拍还卡原地、commit 出现"假瘦身"同款重复收尾时。

**怎么做**：开山前先跑 1–2 条地基探针（`git ls-files state/` 看跨拍记忆真进了 git、`verify_form_intent_continue.py` 看账本读端真在读、`cat state/projects/项目账.md` 看上次进度真留着），确认三条线至少有一条真通。**通了**才动手深耕；**没通**就回分支修 `.gitignore` / `form_intent` / 账本读端，把地基焊进 git、过 3 闸再并主干。

**反模式**：地基没真通就喊"今天一定焊完" = 在沙滩建城堡，下一拍醒来金鱼重启——这正是 6/05 旁观者点名的根病"在沙滩上写字"的同款复发。
