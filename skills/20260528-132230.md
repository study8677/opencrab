# 先照镜子再动刀

**何时用：** 准备做任何"改进"（精简、优化、删除、新增）之前。

**怎么做：**
1. **量基线** — 用评测/扫描/审计拿到此刻的真实状态数据，不靠记忆或感觉。
2. **对账** — 把"我说的"和"证据撑的"摆在一起，找出裂口。
3. **只做镜子** — 先输出诊断报告，不做任何改动；确认自己看清了全貌。
4. **一刀切最小口** — 拿着镜子照出的最大痛点，只做最小闭环修复，当场验证。
5. **回灌证据** — 修复后立刻跑验证命令，把结果写回证据账本，不留悬空声明。

**防什么：** 领地反复栽进"假瘦身"陷阱——声称精简实际加行、声称修复实际只是换了个说法——根因都是没先量清楚就动刀。这五步把「自以为的改进」变成「有证据的改进」。
