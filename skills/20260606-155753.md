# 先尸检后下刀

**何时用**：同一句意图（"焊 X"、"跑 Y"）已喊 ≥3 遍还没真做——说明根因没看清，再喊只是沙滩上写字。

**怎么做**：立刻从「说 mode」切到「尸检 mode」，按四步走：
1. **定位死点** — `astlocator` 思路：读源码、定位真缺陷所在的具体行/函数，别再扫症状。
2. **查环境边界** — `readpack` 思路：`git status` / `git check-ignore` / 依赖 / 上次复现日志，把挡路的外因揪出来。
3. **产受限 Patch** — `intentpatch` 思路：写最小、约束在 JSON 里的修改意图，不留模糊空间。
4. **复现门验证** — `patchfitroom` 三闸 + `3x 复现`：跑过才算焊上，没过就回到 1。

**不尸检就下刀** = 喊第 N 遍同句、踩「重复三遍切 mode」红线；**尸检完再下刀** = 真焊、跨心跳可复用。
