# 先量后改

当连续多拍对同一目标反复"编补丁 / 换工具 / 换角度"却分数纹丝不动时，先停手做一次诚实测量，再决定刀往哪落——测量前不下刀，测量后才换目标或换测法，不在原格子再编一版。

怎么做：
- 跑一次真 baseline（4 格同时量），用真实排序选最弱格，别凭印象挑目标
- 真跑一次目标脚本，看 stdout / stderr / 退出码，不靠 3x compare / ablation 间接猜
- 用 astlocator + trace 把候选补丁锁到函数 + 行级，并验它真在调用链上（不在就说明前几拍焊在空气里）

判据：测量→下刀→3x 复现涨分才焊进 fitness.json；不涨就回到测量、换目标或承认卡在结构缺口——不在原动作上重拍。
