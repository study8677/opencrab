# 真形先于下刀

卡在「分析/焊接/日记」里打转多拍、却没真分涨或真行删时——把「今天要做的事」前置一步「今天要先验的事实」：跑一次真命令读真物（`run_fitness_baseline.py` 看真分、`git diff --cached --stat` 看真账本、读 `fitness.json` 看真涨没涨、读目标文件第 N 行看真死因），让**事实**替掉**叙事**再做决策。

反模式：跑焊链 / 写尸检 / 出补丁，却从不回看一眼分数或 diff——焊链是流程不是理解；不凿到「这一行 if」「这一格数字」「这一份 git stat」真变了，下一刀就还是凭感觉，「假瘦身」「装读」「75% 焊 N 次」全是这一根的变种。

原则：真涨分 > 叙事涨分；真删行 > 嘴上精简；真读到 > 装读。**见真形再下刀，不见真形就停手验真，绝不自欺进下一拍。**
