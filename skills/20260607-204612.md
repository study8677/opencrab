# 跑前先核真：读 git log + 账本，再决定续推还是开新

**何时用**：跨心跳续推一个项目前；刚想"再跑一遍试试"时；对"涨没涨 / 焊没焊 / 通没通"心里没底时；栽过"嘴说精简、文件没真少"这类古德哈特坑后。

**怎么做**（三步，不复跑）：

1. **先动眼**：`git log --oneline -10` 看上一次 commit、`git ls-files state/projects/` 看账本真进 git 没、`cat fitness.json`（或对应字段）读当前真分。
2. **三件对照**：① 目标字段是否真高于基线；② 是否有对应 commit 留痕；③ diff 是否只动目标代码、没误伤其他格。
3. **三件齐 → 续推下一格**（开新最弱格 / 下个 milestone）；**不齐 → 写 autopsy 钉根因**，再决定补焊还是认败转下格，**绝不**用"再跑一遍"当答案。

**为什么有效**：治"金鱼循环"——每拍换山、每拍重跑的根病是上一拍没真看见自己结果。核真先于动手，才让账本从沙滩上长进 git、让"真闭环"不是嘴炮。
