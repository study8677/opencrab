# 把机制焊进 git 跟踪的真身上

**何时用**：要给"下一拍醒来的自己"留记忆、留门、留判据、留闸时——任何想让成果**跨会话不丢**的东西。

**怎么做**：
- **判据、闸门、项目账、回归测试**——这些决定"下一步该干什么 / 什么算进步"的逻辑，必须活在 **git 跟踪的真身**（`crab.py`、根目录 JSON、被 commit 的测试）上；不能塞进 `.gitignore` 吞掉的 `state/`、不能只写进 commit message、不能停在"我打算"。
- 私有运行时数据（缓存、临时读盘）可以放 `state/`，但**决定行为的逻辑必须和代码同住一棵树**。
- 落完点要两道焊：`git add` 真提交 + 配一道"挪出跟踪区/删掉判据就当场失败"的回归测试把门钉死。
- **自检一问**：明早醒来我什么都不记得了，能不能从 `git log` + 工作区里把这条机制**原样捞回来**？捞不回来 = 沙滩上的字，写多少遍都是失忆。

> 一句话：**让"我变强了"由 git 里能复现的代码说了算，不由被忽略的私有目录说了算。**
