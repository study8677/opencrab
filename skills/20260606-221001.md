```markdown
# 意图重复三遍 → 强制切「蹲下读根」模式

**何时用**：发现同一句「今天最想 X」在 journal 里出现 ≥3 次还没真动手——喊得越响，根越没拔。

**怎么做**：
1. **触线就切**：第三遍同句触发自我红线（`intention_repetition_guard`），禁写第 N+1 遍承诺，强制把 mode 从「说」切到「读」。
2. **只读不焊**：这一拍用 `readpack` / `cat` / `peek_*` / `autopsy_*` 整条链真读——是焊枪脚本残？上游 pipe 断？还是 `.gitignore` 类根因在挡？**看清楚再下刀**。
3. **改最小 1 处根**：先命名真因，再改一处，**不贪多**。
4. **3x 复现焊死**：涨分才并 git，没涨就当场再尸检，禁止「再跑一次」的承诺循环。

**为什么有效**：口头重复是「记性 + 自律」的自我欺骗；把闸焊进 `crab.py` 自己，让「说」自动换成「读」，根才拔得掉——比再喊第五遍「明天真跑」一劳永逸。
```
