# 先核真再决策

**何时用**: 同一个山头已经反复打 ≥3 拍、每次都"跑一次再说"、但从未确认上一次是否真落地——即将再跑一遍动作前。

**怎么做**:
1. **停手**,别再复跑。先用 `peek_*` / `git log` / `git diff --cached --stat` 核三件:① 目标文件真变了没;② 数字真涨了没(对比上一次真基线,不接受"涨了一点算涨");③ 焊链 commit 真落了没。
2. **判真伪**:三件全齐→开新格/下一拍;不齐→不补跑,**先写 autopsy 钉根因**("为什么没涨""为什么 commit 没追上"),再决定补焊还是认败转下个格。
3. **黄金法则:核账 ≠ 复跑**。"再跑一遍 X"永远回答不了"X 到底成了没"——只有看账本、看 git、看 diff 才能回答。

**为什么有效**: 反复拍的真实死因不是动作不力,是**不知道自己上一次做到哪一格**就在重起炉灶。把"先核真"从可选项变成每拍的硬前置,跨心跳续推才有真地基。
