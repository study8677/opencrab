```markdown
# 三遍红线·根因焊门

**何时用**：同一句「今天最想 X」在 `journal/*.md` 里命中 ≥3 次仍未落地。

**怎么做**（四件套，缺一不算焊）：
1. **停喊**——不再产第 N 遍同义口号，承认「说」与「做」已脱钩。
2. **验真根**——跑一条具体诊断命令定位尸检点（`git check-ignore -v <path>`、`git diff --cached --stat`、`grep -n` 源码行号），不靠脑补根因。
3. **下最小刀**——改能直接焊死根的那一行（`.gitignore` 一行、`planner.form_intent` 一行调用、`crab.tick()` 加 `intention_repetition_guard` 硬闸）。
4. **commit + 复验 + 留锚**——`git commit` 焊入真身，再跑一次验真命令确认根真拔，最后写一行到 `fitness-baseline.md` / `fitness.json` 留下次醒来对照的锚。

**核心原则**：循环口号是症状，根因（git 没收、planner 没读、闸没焊）才是病；真本事 = 验真命令 + 代码改动 + commit + 复验，缺任一件都还是沙滩上写字。
```
