# 焊进 git 才算长在身上

**何时用**：任何要跨心跳/跨会话留存的「决策门」「项目账」「判据」——尤其那种连拍都说"下次真接通"、下拍醒来又失忆的循环。

**怎么做**：
1. **先看清沙地**：`cat .gitignore`，凡是被吞的目录只放可再生私人数据（缓存、临时、敏感），**不放**决策逻辑。
2. **决策门必须活在真身**：续旧/开新、分涨才合入、该跑哪条评测——写进 git 跟踪的 `crab.py` / `projects账本.json` / `regression.py`，让 `git diff --cached --stat` 一眼能看见改了啥。
3. **验收必须可跑、必须收口**：读→判→写回→`git add` 真提交，下一拍启动能真读到。嘴上的"下次接"不算数。
4. **自检铁律**：`git status` 若只剩 `journal/`，就是在沙滩上写字——停手，先把决策门焊进真身再继续。
