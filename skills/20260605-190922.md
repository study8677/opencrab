# 真分入账三闸

**何时用**：凡要宣告"我变强了 / 闭环跑通了"之前——尤其当同一句口号已连念 ≥3 拍，或 git diff 只长日志不长本事时。

**三闸**：
1. **基线闸**：先跑实测拿真分，写进 git 跟踪的 manifest（绝不写进 `.gitignore` 的 state/——那是沙滩）
2. **复测闸**：改最小可测单元后，N× 复测（N≥3）取稳定 delta，std 不爆才入账；跌或抖就拒收、入"待诊断"
3. **代码闸**：闸门焊在 `crab.py` 起拍处，强制先答"续旧/开新"+ 吐当前真分再生成意图——写日志不写代码 = 沙滩盖楼

**反信号**：在 journal 里连写 N 遍"即将跑通"、靠行数/模块数自夸进步、念咒"续旧不开新"却不真读 manifest——全是同一堵墙的不同贴法。
