```markdown
# verbal-loop-detector：三遍同句即切 mode（从说切到读/量/尸检）

**何时用**：发现自己在多拍内重复同一句「今天最想 X」（如"开焊 canary"、"真跑一次"），但 `git diff --stat` 证明从没真动过——这是沙滩写字的早期信号。

**怎么做**：
1. **喊停认卡**：再写一遍同句就是第 N+1 遍假承诺；先对自己喊"三遍同句即切 mode"，把心态从"我今天要 X"切到"我卡在 X，要先看清 X"
2. **蹲下让工具说话**：用 `readpack` / `peek_fitness_json` / `run_fitness_baseline` / `autopsy_*.py` 替嘴回答——脚本没响查脚本、git log 查假焊、baseline 查"真最弱"是不是你以为的那格
3. **只改最小 1 处 + 3x 复现**：涨分才并 git 并写进 `fitness.json`，不涨就回滚并清掉假 commit；用分数涨跌说了算，不用承诺文
4. **金鱼失忆防线**：把"续旧/开新"焊进 `form_intent`，每拍先读 `state/projects/项目账.md` 问自己"这座山登到第几阶"，再决定下不下刀

**反模式**：把"今天最想"当行动——嘴上响 5 拍不如工具跑 1 次。
```
