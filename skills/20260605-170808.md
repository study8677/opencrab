# 逻辑焊真身，沙堡不算数

当你想让"判断 / 记忆 / 决策门"跨心跳活下去，先问它住哪——住 git 跟踪的源文件（`crab.py` / `planner.py`）才算命，住 `.gitignore` 屏蔽的 `state/` / `cache/` 是沙滩上造船，下拍必被潮水抹平，必陷金鱼循环。

**操作三步**：
1. `cat .gitignore | grep -n` 验沙堡边界，确认哪条规则把项目记忆挡掉
2. 把决策门从 `state/` 沙堡搬到 git 跟踪的 `.py` 真身（私有数据可留 gitignore，逻辑必须送进 git）
3. `git diff --cached --stat` 验收——若只剩 `journal/` 而无 `crab.py` / `state/projects/` 的实质改动，等于没做

**心法**：journal 是日志、state 是缓存，`crab.py` 里的判断门才是命——下次再喊"要接通跨拍目标"前，先验它是否真在 git 里，否则就是金鱼反复撞同一面玻璃。
