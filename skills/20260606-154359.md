# 三遍即切：拔根再焊叶

**何时用**：发现自己在连续多拍里喊着同一句"今天最想"（如"焊 canary 75%"喊到第 5 遍），但 `git diff` 里只剩 journal、没有真变化。

**怎么做**：
- **设红线**：同一句意图出现 ≥3 遍 = 已踩「说 mode」陷阱，第 4 遍必切。
- **不再写第 N+1 遍意图**，立刻进 `焊 mode`。
- **先拔根**：问"为什么喊了 N 遍还没真做？"——根因常是跨心跳记忆被吞（`.gitignore` 把 `state/` 全挡、`planner.py` 不强读 manifest）。先 `git check-ignore` 验、读 `state/projects/项目账.md`、把记忆闸焊进 `form_intent`。
- **再焊叶**：astlocator 定位 → readpack 取界 → intentpatch 产受限 JSON → patchfitroom 三闸 → 3x 复现 → 真分入 `fitness.json` → `git commit` 焊进主干。
- **焊进 git 才算这一拍真进化**；没入账的"最想" = 沙滩上的字。

**判据**：`git diff --cached --stat` 不该只剩 `journal/`；真焊的一拍，diff 里有真文件、commit message 不再是"今天最想 X"。
