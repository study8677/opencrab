# 验产物，再缩范围，再下刀

当一个「今天最想」在多拍心跳里反复出现（措辞变、目标同），根病不是想得不够清，而是**上一步没留下可核验的产物**——commit hash、文件 diff、或 fitness.json 涨分。

**怎么用**：写「今天最想」前先翻最近 3–5 次 commit，看上一次同款目标实际落了哪些文件、动了哪条分数；**没有产物，就只许写最小一步**（「只跑 `git ls-files state/`」、「只翻 `canary.py` 第 X 行」），并明示这一步**结束时拿什么当凭据**。动手时不顺手扩范围——验完一项、commit 一项、凭据到手，再谈下一项。

**反模式**：换说法重写同一目标（「冲 80%」→「登顶真适应度」→「焊进 fitness.json」）、用「闭环」「拔根」等元话语替具体动作、边做边加配套修整。
