# 诊断-行动闭环管理

**何时用：** 当你积累了多轮诊断数据（评测基线、瓶颈扫描、策略PK等），但行动滞后于认知，或者改进停留在框架层面未落地代码时。

**怎么做：**
1. **诚实诊断**：用 `evalbench`、`bottleneck`、`organ_autodiag` 等工具做最小探针，拿到真实基线与弱点。
2. **收益排序**：用 `opportunity.py` 或手动将诊断结论按「影响×可行性」排序，锁定最高收益方向。
3. **场景验收**：用 `scenarioforge.py` 或手动为选定方向铸一个最小可跑场景（非框架，真代码路径），端到端跑通。
4. **证据固化**：将场景验收结果（通过/失败、改进点）回灌到 `skillgraph` 或对应文档，形成“诊断→行动→验证→记录”的闭环。
