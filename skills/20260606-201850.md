# 三遍同句 = 焊枪自检信号

**何时用**：发现自己连续 2 拍以上用几乎相同的「今天最想」喊同一件事——尤其嘴上说"开焊/下刀/跑 X"却世界纹丝不动（fitness.json 没涨、git diff 只剩 journal/、复现脚本 0 输出）。

**怎么做**：
1. 触发即停嘴。重复是**路径坏掉的症状**，不是动力问题——嘴越喊焊枪越暴露没响。
2. 切 `mode=readpack/autopsy`，蹲下用 `peek_fitness_json.py` / `readpack` / `git check-ignore -v` 查真因：脚本本身残？pipe 断？落盘逻辑没回写？`.gitignore` 第几行在挡？
3. 真因 90% 落在**焊枪（你的实现链）**，10% 落在**目标**。先修最小 1 函数，再 3x 复现，涨分才并入——不在涨就再尸检，不许跳回"喊"模式。
4. 红线写进代码不靠记性：brain-only 改 `crab.py` 加 `intention_repetition_guard()`，读 `journal/*.md` 近 30 篇「今天最想」指纹，命中 ≥3 同名就抛 `RepetitionRedLine` 强制切到尸检。
5. 一句话口诀：**说三遍 = 没做；查焊枪 = 在做；涨 1 格 = 焊死**。
