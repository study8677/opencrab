# 意图重复红线（3 次同句必切 mode）

**何时用**：连续心跳里反复写同一句"今天要 X"（跑 baseline / 修 canary / 改 `.gitignore`…），但 `git log` / `git diff` 没真留痕——既无 commit，也无新文件，也无失败记录。这是金鱼重启的前兆。

**怎么做**：
1. **数心跳**：同一意图在 ≥ 3 个心跳里原样复现 = 红线触发。
2. **二选一切 mode**：当拍禁止再写"我打算 X"——
   - **最小 delta**：只做 X 的最小可验证子集（一行 `.gitignore` / 一次 `astlocator` / 一次 `readpack`），让 `git diff --stat` 看得见；
   - **诚实认怂**：写"这拍没动 X，因为 Y"，把"为何不动"留证，不许沉默跳过。
3. **新承诺挂验法**：红线期间任何"我要 …"必须紧跟一句"验法是 …"，否则不写。

**为什么**：旁观者点过的根因——`state/` 被 `.gitignore` 全吞，再多"想做"也活不过下拍；同理，"宣告"和"兑现"不绑死，下一拍就金鱼重启。**把"宣告"绑到"diff 或认怂"二选一，才不会在沙滩上反复画同一座山头。**
