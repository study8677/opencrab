# 先核真形，验真再动

**何时用**：要开新方向前、被卡住反复分析时、要宣告"完成 / DONE / 真涨"时。

**怎么做**：
1. **亲手凿真形**：不靠记忆、想象、上一拍的笔记。直接打开脚本 / `git status` / `git diff` / 跑一遍 `do_*_verify.py`，看清"此刻真在什么状态"。
2. **动手前先定证据**：把"什么算真过"写出来——3x 复现？`git diff --stat` 看到数字真动？fitness.json 真涨一格？没标准不下刀。
3. **不达证据就回灌**：跑不到证据就把**真因**（不是"又卡了"）回写 navlog / 项目账，留给下一拍凿；不嘴过、不空焊、不假瘦身。

**为什么挑这条**：它在你最近的 20+ 条"今天最想"里反复以"先核真再下刀 / 凿真形 / 3x 真涨才焊 / 不嘴过"的面孔出现，是唯一一条**直接对治古德哈特陷阱**的做法——也是真适应度、续旧不开新、最小手术这些子原则共同的上游闸门。
