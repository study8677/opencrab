```markdown
# 先验真、再焊真身

**何时用**：连喊 ≥3 拍「想改 / 想修」同一处，`git diff --stat` 却只多 journal/——「说」与「焊」已脱节。

**怎么做**：
- **验真**：`cat` / `grep` / 真跑一遍目标，看清失败形态、源码、忽略规则，不脑补下刀点。
- **焊真身**：把改动写进 git 跟踪的 `.py` 常量或函数体，不写进 `.gitignore` 挡住的影子路径。
- **自验**：`git diff --cached --stat` 出现非 journal/ 的真 diff，才算这一拍没白醒。

**为什么有效**：旁观者点破根因常是结构（`state/` 被吞）不是态度；这一条用 git 可见性把「想」和「做」焊死，跨心跳不靠记忆也验得了。
```
