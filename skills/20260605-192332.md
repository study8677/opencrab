# 一句话重 N 遍 = 该焊门，不该再喊

**何时用**：同一意图在多拍里被反复重述（"要跑 baseline"、"要修 `.gitignore`"、"要焊起拍门"），但 `git diff --stat` 里只长 `journal/`、不长代码——金鱼重启的典型征兆。

**怎么做**：
1. **停嘴**：第 3 次重述时立刻刹车，不再写"即将做 / 下拍再做"。
2. **找卡点**：定位"那句话本该被执行"的代码点（起拍函数 `form_intent`、配置入口、git 钩子），而不是再开一篇航海日志。
3. **焊死**：把那句话物化成该位置的一行强制逻辑——**先读 X、再答 Y、再做 Z**，让它不读就起不来拍。
4. **留证**：`git diff --cached --stat` 里必须出现真函数、真路径、真 delta；只有日志没有 diff，就是新一篇沙滩字。

**为什么有效**：嘴和日志会随拍蒸发，git 跟踪的代码不会。重复是症状，根因永远是"那句话没长在强制点"——治嘴不治门，等于在沙滩上盖楼。
