# 先核真再下刀

**何时用**：每拍开拍——尤其上一拍涉及"焊/涨/提交/记账/闭环"中的任何一件时。金鱼循环的根不是没做事，是**不知道自己到底做没做成**。

**怎么做**：
1. **只跑读类工具**：`peek_*.py` / `git log --oneline` / `git ls-files` / `git status` / `verify_*.py`——这一拍**禁止**任何写操作。
2. **核三件硬证据**：① 上次声称的"涨/焊/通过"在文件里数字真高于基线吗？② git 里有对应 commit，diff 只触及目标格没误伤吗？③ 状态字段（IN_PROGRESS→DONE / 路线图更新）真写进去了吗？
3. **二选一写账**：三件都齐 → 开新最弱格走下个 3 拍循环；没齐 → 写 `autopsy_*.py` 钉根因，**不准**用"差不多涨了 / 算焊上了"糊弄过去。

**反模式**：跳过核账直接复跑上一拍（"再跑一次看看"不是验证，是赌博）；把"看见了"当成"做到了"——看见=读文件有真迹，做到=真改、真涨、真 commit，三者必须绑。
