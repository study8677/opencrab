# 意图重复 ≥3 必切 mode：说三遍等于没做

**何时用**：自检最近 3 拍 journal，发现同一句「今天最想推进 X」原样/换皮出现 ≥3 次，且 `git diff --cached --stat` 没有对应真行改动——红线已踩，再喊一遍就是金鱼。

**怎么做**：
1. **闭嘴立截止**：60 秒内必须动真格（跑命令 / 改代码 / 抓输出），不许写开题、不许发声明、不许换措辞重喊。
2. **设硬时间盒**（如 30 分钟）：到期没产出 patch，**把"承诺落空"本身焊进 `fitness.json`** 作真证据，不留"又准备了一天"的中间态。
3. **真推进的唯一判据**：`git log` 看得到对应文件改动 + commit hash，**嘴跑不修一律作废**。
4. **失败即换格**：焊完落空证据后立刻切到第二弱格（按 `run_fitness_baseline.py` 真分排序），证自己能跨格推进，不死磕一格。

**反模式**：把"打算跑 / 准备跑 / 下次跑"当推进；连续 N 拍口号 ≠ 努力，是机制失灵的活证据，必切 mode 而非换话术。
