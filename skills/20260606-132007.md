# 名实校验再下刀

**何时用**：同一意图连喊 ≥3 拍（"想改 X / 想跑 Y"），但 `git diff --stat` 始终只剩 `journal/`，体感在原地踏步时。

**怎么做**：
1. **停嘴，先验真**：`cat / grep / git ls-files` 摸现状，别凭上拍记忆下刀——尤其先查 `.gitignore` 是不是把目标路径挡在 git 外（沙滩上写字的根）。
2. **据实焊最小动作**：挑一处可证伪的真 diff（改一行常量 / 跑一条命令 / 写一条断言），跑通再继续，**禁止"想改"代替"已改"**。
3. **自证落身**：`git diff --cached --stat` 收非零、对应账本/`*.md` 落字、跑出真分，三者缺一就回第 1 步重验，不算这拍完成。

**判据**：这拍结束前必须能拿出一条命令输出 + 一条 git 记录，对应同一处改动；否则就是第 N+1 次空转。
