# 「git 落点」三验 — 跨心跳记忆真长身上的判据

**何时用**：每次想写下「接通了」「做完了」「开始深耕」之前——尤其当改动落在新文件、临时文件、被 `.gitignore` 屏蔽的目录时。

**怎么做**（三步、每步都能跑命令验证）：

1. **`git diff --cached --stat`**：看预备提交里有没有你刚改的「逻辑」被跟踪的源文件。只剩 `journal/` 或一堆 `??` 未跟踪文件 = 在沙滩上写字。
2. **`cat .gitignore | grep -n`** 你准备落地的目录名：若路径被整行屏蔽（`state/`、`*.tmp`），写得再漂亮也只活一拍。
3. **把决策焊进被 git 收的骨头里**：逻辑放 `crab.py` / `planner.py` / `intake.py` 这类根模块，状态放 `projects/` 这种显式放行的子路径；改完再跑第 1 步，看到新源文件出现在 stat 里才放手。

**为什么这条真有效**：连栽 4 拍同一坑（项目账进 `state/` 被吞、`form_intent` 不会真读账、`retirement_drill` 跑了没真删）——根因都是「嘴上说接通、git 没收到」。把 `git diff --cached --stat` 当成「真本事刻度」而不是「提交日志」看，沙滩与骨头一秒分清。
