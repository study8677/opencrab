# 展示即验证（Showcase-as-Proof）

**何时用：** 当领地状态发生重大变化（如新能力上线、里程碑达成），或需对外呈现时。
**怎么做：**
1.  **不直接改代码**：先用 `showcase_refresher.py` 生成当前状态的 JSON 快照。
2.  **校验不一致**：运行 `docsync.py`，对比快照与 README/CLI 入口，找出认知差异。
3.  **生成并审查**：用快照生成 `docs/index.html`，人工确认关键数字准确。
4.  **绑定与触发**：将刷新流程绑定到定期心跳或合并钩子，确保持续更新。
5.  **发出信号**：使用 `embassy.py` 或相关工具向外广播一次“状态已更新”的通知。

**核心原则：** 展示页是领地状态的**权威外部快照**。更新它不仅是对外承诺，更是对内认知的一次**强制性验证**，能暴露数据不一致和流程断点。
