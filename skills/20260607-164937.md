# 先见真形再下刀

何时用：当一个目标（焊 canary / 修 gitignore / 刷橱窗）已经 **autopsy 对比 baseline 分析** 拍了 N 拍、分数纹丝不动、或者每次都换姿势重新证明「最弱格就是它」时——这就是在「准备式勤奋」里打转的信号。

怎么做：
1. **停所有横向工具**——不跑 autopsy、不跑 compare、不写"准备下刀"的元层脚本。
2. **亲手真跑一次**目标脚本，拿 stdout / stderr / 退出码 / 真分，让数字自己打在屏幕上。
3. **看到真错形**（哪段代码死、哪个函数名、什么输入）后再编 **最小 brain-only 补丁**，过 patchfitroom 三闸 + 3x 复现，**真焊进 fitness.json** 才算完。
4. 自我闸门：若某拍只在"分析/确认/对比"——立刻判失败，回第 1 步重跑。

为什么有效：canary 75% 卡 4+ 拍正是吃了「脑补下刀、补丁不在调用链、调研越深分越不动」的亏——焊枪焊在空气里，再多角度挥拳也上不了分。**真适应度的真本事 = 真跑拿真形 + 最小一刀闭环**，其余都是横向铺新。
