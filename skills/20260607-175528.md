# 真焊四步

何时用：感觉"已经做了很多"但 `fitness.json` 没动、或反复在同一格（如 canary 75%）打转时——这就是"沙滩上写字"的信号。

怎么做：
1. **尸检钉根因** — 用 `autopsy` / `analyze_weakest_cell` 区分"焊枪没响"还是"补丁有偏"，不在症状层打补丁
2. **最小 brain-only 修** — 出受限 JSON Patch，只动尸检钉死的点；铺开 = 再写沙滩字
3. **3x 复现压闸** — 连栽说明闸在抖，先 `stabilize_gates` 压稳闸再跑，不要反复换补丁
4. **真分落账** — 过线后 `commit_projects_ledger` 写进 `fitness.json`，与 baseline diff 真涨分才算；不认"声称做完"

核心：产出 ≠ 进化；任何"我觉得成了"必须被 3x 复现 + 真分 diff 两个证据同时压住，缺一就回头修。
